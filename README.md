# Mega Kit Pequeno Engenheiro

Página de vendas do Mega Kit Pequeno Engenheiro (70 projetos para crianças, em português de Portugal).

- Ficheiro único: `index.html` (CSS, imagens e scripts incluídos)
- Inclui o Meta Pixel na `<head>`
- Para publicar: GitHub Pages (Settings > Pages > branch `main`, pasta `/root`) ou qualquer alojamento estático

## Antes de publicar
- Link do checkout (Hotmart) já configurado no botão da secção `#oferta`.
